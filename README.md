# hlp-engine

Python project to create an engine capable of creating any type of Professor Layton's puzzles (limited to DS puzzles)

## TODO

### Interface

Player :

- Description of the puzzle
- main puzzle interface (image representing the puzzle)
- Note interface
- Answer interfaces

Puzzle-maker :

- Puzzle making interfaces (all puzzles)

### Type of puzzles that will be supported

- "Board' Puzzles : Failsafe if puzzle has no solution | Multiple objective puzzles + automatic solving
- Choose the right answer puzzle
- Enter a number / character
- Circle the answer
- "Draw lines puzzles" --> i.e Puzzle 012 Layton1, Puzzle 068 Layton3, Puzzle 118 Layton5
- Place elements puzzles --> i.e. 8 queens problem Layton1, Puzzle 004 Layton4

### Out of the scope (for now)

All puzzles that need very specific elements such as additionnal physics, specific ruleset (Wolf, goat and cabbage problem), microphone usage...
